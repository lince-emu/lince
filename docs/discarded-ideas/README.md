# Discarded ideas

Ideas that were considered seriously and set aside, so they are not proposed again without
new evidence. Each file states the idea, who discarded it and when, why, and what would make
it worth reconsidering.

This folder is not a list of rejected ADRs: an ADR alternative that loses stays in its ADR.
Ideas land here when they were discussed outside an ADR, or when the reasoning is worth
keeping in more detail than an ADR's alternative list holds.
