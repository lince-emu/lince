# Research notes

Behavior specifications derived from research (protocols, register semantics, instruction
semantics, observed edge cases). Never code.

Each note must state:
- **Source:** repository, branch, commit, file (or document / measurement method).
- **Evidence level:** SRC, DOC, DOC-MEASURED, MIRROR, RECALL, or VERIFIED (reproduced by Lince).
- **Applies to Lince:** yes / no / partially, with reason.

Third-party data under a Creative Commons Attribution licence (for example the Vulkan Hardware
Database, D-007) needs an **Attribution** line in the note: creator and copyright notice as the
source shows it, the source URL plus each record used (full URLs, or a URL pattern plus record
ids), a link to the licence, and a
statement that the tables are excerpts transcribed by Lince.

Suggested files: `nvn2-command-buffers.md`, `nx2-services.md`, `ampere-sass-encoding.md`,
`mme64.md`, `qmd3.md`, `syncpoints-and-semaphores.md`.
